## 设置与会话显示

- 新录音选择器仅展示 AAC、MP3，能力查询仍控制选项是否可用；M4A 只保留旧文件及旧活动会话兼容，不作为新录音选项。
- AAC 提供中英文说明“ADTS 文件，后缀 .aac” / “ADTS file, .aac extension”。保留“用于下一次录音，已有录音保持原格式”提示、即时保存、失败重试、保存期间禁用重复操作与返回的既有行为。
- AAC 开始失败提示用户在设置中主动选择 MP3；MP3 不可用时提示主动选择 AAC。偏好不自动改变，不静默回退。
- 复用原生状态中的实际会话格式，暂停 AAC 后修改默认格式仍显示并继续 AAC；升级保留的 M4A 会话仍显示并继续 M4A。格式标签继续使用 AAC、MP3、M4A，中英文一致。

## 分享

复用既有通用分享服务，无需新增转换或临时文件清理逻辑。按条目自身格式使用 `.aac` / `audio/aac`、`.m4a` / `audio/mp4`、`.mp3` / `audio/mpeg`，与当前默认偏好无关。

标题命名副本、非法字符处理、同后缀去重、不同后缀保留、成功/取消/失败清理及原件保护保持。新增 AAC 标题与后缀测试，将主界面分享回归扩展为三种格式分别在其他默认偏好下分享；原有三格式 MIME 和临时副本清理测试共同覆盖调用链。测试使用字节夹具与模拟分享面板，不代表真实音频或接收应用兼容性。
