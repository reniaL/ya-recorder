# 真机备份启动失败：选择器返回与窗口焦点

日期：2026-10-18。范围：BKP-03/06 启动可靠性及错误诊断，不关闭完整端到端验收。

## 原因与证据

用户报告选择保存位置或导入文件后偶发出现“任务失败，请检查文件访问权限和可用空间后重试”，随后重试导出成功。该文案对应 `BackupFailure.unknown`，不代表已经确认文件授权被拒绝。

`BackupPlatformBridge` 在启动 `startCopy`、`startExport`、`startImport`、`placeImport` 前检查 `Activity.hasWindowFocus()`。文档选择器返回的结果在元数据查询后直接交给 Dart，并不保证窗口已恢复焦点。旧逻辑在这个间隙抛出 `foreground-required`，再被归入未知错误。导入和导出共享此路径。

设备为 Android 测试设备，Android 13/API 33。初始任务日志为 `direction=read/status=cancelled/processedBytes=0/released=true`，未保存原始启动异常；不能据此认证历史失败的唯一原因。修复后真机实际捕获：

```text
10-18 11:31:37.710 I BackupPlatform: Waiting for returning window: startImport
10-18 11:33:21.537 I BackupPlatform: Waiting for returning window: startImport
10-18 11:34:00.782 I BackupPlatform: Waiting for returning window: startImport
```

前两次随后进入预览并完成重复导入；第三次顺利开始读取，按预期拒绝一个非本应用备份 ZIP。这证明选择器返回后启动命令早于窗口焦点的情况在该设备确实存在，旧检查会拒绝这些命令；不将其他可能的 provider 故障统称为此原因。

## 修改

- 增加主线程 `BackupForegroundGate`，失焦时等待真实窗口焦点回调，最多 5 秒；已聚焦的操作立即启动。保留原有前台检查和系统前台服务限制。
- 超时或 Activity 销毁时完成失败并清除待启动操作；迟到的焦点回调不会再次启动，重复请求不会替换原请求。监听器在 bridge 销毁时移除。
- 为启动失败提供独立的中英文提示，未知错误不再引导用户误判为权限问题；实际文档权限错误仍单独提示。
- 服务启动异常保留异常类型和消息；原生工作失败、平台命令失败及 Dart 工作流失败写入诊断日志，避免仅有笼统 UI 提示。
- 回归发现备份保护解除后目录选择器刷新使用 `setState(() => future = ...)`，回调返回 Future 导致 debug 断言。刷新与重试改为不返回值的同步闭包，已有备份后刷新回归通过。

## 验证结果与边界

- `flutter analyze --no-pub`：通过。
- `flutter test --no-pub test/backup`：94 项全部通过。
- `:app:testDebugUnitTest`：130 项通过，含 5 项新增焦点门禁测试，覆盖立即启动、等待/只启动一次、超时、销毁、重复请求。
- 普通 debug APK 构建、保留数据覆盖安装：通过。
- 真机系统选择器导出：原包一次、修复后两次成功；备份为 9 条录音、4 个文件夹、1,444,892 字节。导出包拉回桌面，通过 `tool/verify_backup_export.dart` 独立 v1 契约及全部 SHA-256 校验。
- 真机导入修复后导出的包：两次成功，均新增 0 条、重复跳过 9 条、差异冲突 0 条，无重复入库。非备份 ZIP 被正确归类为格式错误，失败后任务释放。系统返回取消文件选择时不新建任务。
- 测试前后私有库快照对比：9 条录音及 4 个文件夹的全部数据库字段相同，9 个音频文件 SHA-256 全部相同。
- 当前全量 Flutter：305 通过、30 失败。隔离检出未修改的 `7bff85e`：303 通过、32 失败；当前 30 项失败全部在基线存在，集中于既有设置/目录选择器等界面查找。全量回归不能记为通过。基线额外失败中的目录刷新已修复；另一项 native-progress 用例本轮当前通过、基线失败，按时序波动保留，不作为额外修复证据。

原安装包一次导入在原生检查完成后停留、取消未及时完成；重新安装当前源码构建后两次同包导入均正常，本次未独立定位原包停留原因，不声称焦点修复已解释该现象。

本次未覆盖其他文件提供方、真实权限撤销、空间不足、进程终止/换机恢复、ZIP64 或大包，也未关闭 BKP-02～06 的其他设备条件。测试原始快照、导出 ZIP 和日志保留在本地忽略目录 `build/`，不提交用户音频、标题或原始文件目录清单。
