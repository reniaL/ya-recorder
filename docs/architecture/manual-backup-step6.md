# BKP-06：完整交互与本地化

实现日期：2026-10-15。状态：设置入口、导出摘要、导入预览、任务进度和结果页面已交付，自动化与普通 debug APK 构建通过；Android 实际通知/返回/前后台和操作禁用待设备验收，保留“进行中”。对应 [七步计划](manual-backup-and-restore-implementation-plan.md)第六步。

## 入口与任务归属

设置新增“备份与恢复”，不新增主导航。入口显示当前任务或上次结果。主界面的保护说明也提供当前任务入口。

[BackupController](../../lib/backup/backup_controller.dart) 由应用首页持有，复用既有协调器及导入/导出服务，页面仅观察状态和提交确认。任务不捕获页面 Context、语言或主题；返回设置、主界面、页面销毁或重新进入都不取消任务。确认等待由控制器持有 Future，确认/取消后继续原任务，不重做导入、不取得第二份租约。应用所有者销毁时会结束尚未回答的确认；不因关闭单个页面销毁控制器。

[BackupPage](../../lib/backup/backup_page.dart) 使用可滚动内容和可换行按钮。导出摘要包含正常录音与空文件夹数量、音频总量、独立的临时 ZIP 估算及可能的本地目标副本空间，并明确未加密、未知目标容量、开始时重新检查快照。用户选择保存位置后才取得保护；取消选择器不开始任务。默认文件名按当前设备本地时间生成。

导入先选择源并整包验证，再展示备份时间、新增录音/文件夹、重复/差异冲突跳过，以及可滚动查看的自动改名列表。确认前无业务入库，确认说明相同 ID 不覆盖、不复制，包含最近删除查重规则。预览可离开再进入；等待时原生工作服务已停止，主要通过设置或主界面任务入口返回，不维持无限前台服务。

## 进度、取消与保护

页面分别显示准备、检查、打包、校验、保存、导入及提交阶段。字节进度与条数为真实阶段事实，不使用伪造的整体百分比；未知总量使用活动指示。修正原生导入检查的条数统计，JSON 两个条目不再算作录音。

提交前可明确取消；取消后显示安全取消状态，等待服务与清理结束才释放保护。短入库阶段显示“正在完成导入，暂不可取消”并禁用取消。页面返回不等于取消。

- 主界面禁用新录音及录音重命名/移动/删除，显示原因并保留浏览、播放和分享。保护开始时退出批量选择，存储和原生业务门禁继续作为最终保证。
- 文件夹管理禁用创建、重命名、删除和排序；任务结束后刷新文件夹，避免沿用排序草稿覆盖新导入文件夹。
- 最近删除页仍读取已有记录，禁用恢复/永久删除并显示原因；保护期间不等待延期清理而把浏览页阻塞成加载态，结束后重新加载和清理。
- 浏览用文件夹选择器监听保护转换，在任务结束时刷新一次，包括选择器已打开的情况，不对每次字节进度重复查询数据库。移动选择器在可修改时重新读取存储，业务门禁处理迟到确认竞态。
- 设置中的语言、主题和默认格式仍可调整；中英文和主题在重建页面时读取，不重启原任务。

## 结果、恢复与分享

导出成功显示文件名、URI、数量和实际 ZIP 大小，提示另存至手机之外，并可分享原生保留的临时 ZIP。分享使用现有 share_plus 的 `application/zip` 和显示文件名，不删除原生 24 小时保留副本；仅报告交给接收应用，不报告远端上传。分享取消不报错，副本失效/分享异常不会改变已经保存成功的结果。

导入结果显示新增、重复、差异冲突及新文件夹，并保留改名列表；完全重复显示无新增，空文件夹可独立恢复。提交后清理告警保留成功结果。失败原因按损坏/版本、ZIP64、空间、授权、本地文件异常、中断、清理及其他错误映射为本地化说明，不直接显示原生异常或私有诊断路径。无法删除的目标半成品单独显示其 URI。

原生任务 journal 记录显示文件名和有界导入统计摘要。摘要在预览前落盘，只是统计，不代表提交成功：重启导入结果仍须有原生 `accepted` 或启动恢复从 SQLite 同事务标记判定的同任务提交结果。恢复信息带任务 ID，不能用其他遗留任务的提交结果认证当前任务。重启后恢复最近一次导出结果或导入统计/实际中断说明；不是备份历史功能。重启后的导入摘要保留数量，完整改名列表仍在当前应用会话的导入计划中。

启动恢复失败时，录音写入仍被既有屏障拒绝；首页提供查看入口，设置/备份页可打开并解释错误、禁用新任务和重试恢复。重试成功恢复操作并刷新列表，归属不明的数据不会被 UI 绕过屏障删除。残留目标也可重试原生清理。迟到的初始化快照有版本保护，不会覆盖用户已经开始的新流程。

## Android 通知与双语言

现有通知阶段增加“导入文件”；切换语言时立即请求正在运行的备份通知刷新。通知打开使用任务 ID，经 MainActivity 的冷启动 Intent / `onNewIntent` 和备份 MethodChannel 转交控制器；仅匹配当前任务或最近结果，忽略旧任务请求，已打开的页面不重复压栈。Dart 订阅先安装回调，再读取保留的打开请求。

全部新增页面、结果、错误和数量进入中英文 ARB；英文数量覆盖零、单数和复数，日期和字节数使用当前语言格式。浅深色使用主题组件。当前 ZIP64 导入拒绝及大包恢复缺口保持，并在入口与失败原因中明确说明；本轮不扩大备份协议或迁移数据库版本。
