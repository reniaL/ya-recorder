# 用户流程

本文描述丫丫录音 MVP 的用户操作流程和关键结果。它用于指导交互设计、功能实现与验收；具体视觉样式、控件位置和文案可在 UI 设计阶段细化。

## 全局约定

- 主界面以录音列表为核心，并提供始终易于触达的开始录音入口。
- 录音尚未停止并安全保存前，不将它作为普通录音显示在列表中。
- 一次只能存在一条进行中的录音，也只能播放一条录音。
- 所有会丢失数据的操作均需明确确认；用户取消确认后保持原状态。
- 用户主动分享、永久删除和前往系统设置会离开应用当前流程；返回后应尽量恢复上下文。

## 快速录音

1. 用户在主界面触发开始录音。
2. 若尚无麦克风权限，应用请求系统权限。
3. 获得权限后，应用读取默认录音格式并固定为本次会话格式，准备录音并进入录音中状态，显示录音时长与暂停、停止、取消操作。
4. 用户选择停止时，应用完成剩余编码缓冲、文件收尾和索引提交，期间显示“正在保存”；MP3 在录音期间实时编码，停止后不转换整段录音。
5. 保存成功后，应用返回录音列表或保存结果视图；新录音以默认标题显示在当前文件夹或全部录音中。

成功标准：用户从开始到看到可播放的新录音，不需要输入名称、选择目录或登录。

正常保存成功的顶部提示约 4 秒后自动消失，用户也可手动关闭；异常中断的保存结果应明确说明中断和已录部分的去向，不使用普通成功提示的自动消失规则。

## AAC / ADTS 目标流程（REC-08，待实现）

完成后，“更多 → 设置”提供 AAC、MP3，初始默认 AAC；升级将 M4A 默认偏好改为 AAC，MP3 偏好保留。偏好即时保存、重启保持、下次会话生效；活动会话和旧草稿仍用原格式。AAC 直接录制为 `.aac` / ADTS，停止只收尾、验证和保存。旧 M4A 继续播放、管理和分享，不转换；编码失败准确反馈，用户主动选择其他格式，不自动切换。详见 [实现计划](../architecture/aac-adts-plan.md)。

## 选择默认录音格式（REC-07 基线）

REC-08 第三步已接入共享原生 AAC 后端，初始及原 M4A 默认偏好为 AAC，MP3 偏好保持；原生新录音能力为 AAC/MP3，第五步选择器仅显示 AAC、MP3，并按能力启用，AAC 附中英文 ADTS/.aac 说明。活动会话保持实际格式，旧 M4A 内部兼容保留；第四步已接入保存/恢复验证，第五步设置/显示/分享回归通过，用户已于 2026-10-14 确认 AAC 设置、录音、播放、分享等功能真机测试正常，REC-08 已完成。下方初始默认 M4A 的流程保留 REC-07 当时基线，验收依据见 [真机反馈](../device-feedback.md#aac-功能验收确认2026-10-14)。

1. 用户进入“更多 → 设置”，查看“默认录音格式”及当前选择。
2. 点击后以单选方式选择 M4A 或 MP3，初始默认 M4A。
3. 应用即时保存偏好，成功后更新当前值；写入失败提示重试并保留原值。
4. 返回列表后开始新录音，使用已保存的默认格式；应用重启后保持该选择。

设置说明为“用于下一次录音，已有录音保持原格式”。若已有进行中的会话，修改默认值也不改变该会话；用户不需要在每次开始时重新选择。MP3 编码器不可用时明确说明无法开始 MP3 录音，用户可返回设置选择 M4A，不自动改变偏好或文件格式。旧 M4A 录音继续按原格式播放、管理和分享。

## 选择主题

1. 用户进入“更多 → 设置 → 主题”，查看当前选择，初始为“跟随系统”。
2. 选择跟随系统、浅色模式或深色模式；应用保存成功后立即更新界面，重启后保持。
3. 跟随系统时，系统切换浅色或深色，应用随之切换；手动选择时保持指定主题。
4. 保存失败保留原主题，显示错误并允许重新选择；读取失败可重试。切换过程中录音与播放继续保持原状态。

## 选择语言

1. 用户进入“更多 → 设置 → 语言”，初始默认“简体中文”。
2. 选择“简体中文”或“English”；取消、返回或选择当前语言不写入。
3. 保存成功后，页面、弹窗、提示、无障碍描述及录音通知立即使用所选语言，重启后保持。写入失败保留原语言并提示重试。
4. 切换时活动录音、播放进度、主题与格式设置保持。已有录音标题和文件夹名称不翻译；新保存录音的默认标题使用当前语言。

## 权限被拒绝

1. 用户触发开始录音，系统拒绝麦克风权限。
2. 应用不创建录音条目或空文件。
3. 应用说明录音需要麦克风权限，并提供再次请求和前往系统设置的入口。
4. 用户不授予权限时，仍可浏览、播放和管理既有录音。

## 暂停与继续

1. 录音中用户选择暂停。
2. 界面切换至已暂停状态，已录时长保持不变，并突出继续与停止操作。
3. 用户选择继续后，应用回到录音中状态，并向同一录音继续写入。
4. 用户停止后，暂停前后内容作为一条完整录音保存。

若继续录音失败，应用保留已经录下的部分，按录音生命周期中的异常策略完成保存或告知用户结果。

## 取消未完成录音

1. 录音中或已暂停时，用户选择取消。
2. 应用提示该操作会放弃当前尚未保存的录音。
3. 用户确认后，应用停止录音、删除临时数据并返回此前页面。
4. 用户取消确认后，继续保持原录音状态。

确认放弃完成后显示“本次录音已放弃”，约 4 秒后自动消失，也可手动关闭。连续成功提示只显示最新一条并重新计时；开始下一次录音清除此前提示。

## 回放录音

### 在列表中快速回放

1. 用户点击录音行的播放按钮，在列表内播放并显示简洁底部播放器，不打开详情；再次点击暂停或继续。
2. 用户可查看标题、当前位置和总时长、拖动进度。倍速选择和快进/快退操作放在详情页。
3. 点击另一条录音的播放按钮时，停止当前播放并切换为新录音。

### 在详情页专注回放

1. 用户点击录音标题或录音行其余区域，进入独立详情页并立即自动播放；也可点击底部播放器标题进入。多选模式下行点击仍仅切换选择。
2. 若所选录音已在播放或暂停，保留当前位置与倍速并继续播放；选择另一条则停止原播放，从新录音起点播放。两个界面共用一个播放状态。
3. 用户可播放/暂停、拖动进度、选择 `0.75×、1×、1.25×、1.5×、2×` 倍速，或按音频时间快进/快退 5 秒；跳转不超出录音范围，暂停时跳转保持暂停，到达末尾后结束播放。
4. 顶部返回、系统返回或返回手势均停止播放，回到此前列表范围、搜索条件与滚动位置，并收起底部播放器；不恢复进入详情前播放的其他录音。加载中返回不得在加载完成后自动播放。

自然播放结束后，播放状态回到未播放，进度回到起点；详情页不自动退出。切后台或锁屏不等同于返回列表，不触发“返回即停”，相关播放策略另行定义。

详情页标题右侧的更多菜单支持重命名、移动到文件夹和分享。重命名与移动沿用列表页已有对话框和目标选择器；成功后详情页立即显示新标题或归属，继续停留并播放当前录音。分享沿用系统分享面板，以当前录音标题命名附件，并依据录音实际格式设置扩展名和 MIME 类型。备份保护期间不可重命名或移动。

若文件因外部操作不可读，应用显示错误，不应让播放器停留在错误的播放状态，并提供移除失效索引的后续处理入口。

## 查找与整理

### 搜索录音

1. 用户进入搜索，输入框提示当前搜索范围（“搜索全部录音”或“搜索「文件夹名称」中的录音”），并输入标题关键词。
2. 列表即时或经短暂防抖后显示匹配当前范围的录音。
3. 用户清除关键词后，恢复原列表和排序。
4. 无匹配项时显示空结果状态，但不改变任何录音或文件夹数据。

关闭搜索后恢复当前目录标题及此前的列表上下文。

### 切换录音浏览范围

1. 用户通过顶部醒目的目录标题确认当前范围（“全部录音”或具体文件夹名称），点击名称及其右侧下拉箭头所在区域。
2. 应用在目录标题旁打开圆角浮动菜单，顶部被省略的长名称可在菜单中完整查看；文件夹较多时菜单内部滚动。
3. 用户选择“全部录音”或任一文件夹，应用立即更新目录标题及对应录音列表并关闭菜单，不改变录音数据；多选中的选择按既有规则清空。用户可点菜单外或系统返回取消。
4. 若处于搜索状态，搜索提示随当前范围更新，搜索继续仅作用于当前范围。

### 创建文件夹并移动录音

1. 用户创建一个文件夹，并输入有效名称。
2. 应用创建逻辑文件夹；不要求用户为其选择真实磁盘路径。
3. 用户从录音操作菜单选择移动，并指定目标文件夹。
4. 应用更新录音所属分类，录音文件本身无需因为分类而移动。

### 调整文件夹顺序

1. 用户进入文件夹管理，至少有两个文件夹时点击顶部“排序”。
2. 应用显示拖动提示、右侧手柄及“取消”“完成”，收起创建、重命名和删除入口。
3. 用户从手柄拖动文件夹调整先后顺序，靠近屏幕边缘时列表自动滚动；也可通过辅助功能或行菜单的“上移”“下移”操作调整。
4. 点击“完成”后，应用一次性保存顺序；保存期间显示进度并禁用重复操作与退出。保存成功后退出排序模式，各文件夹选择器使用同一顺序，重启后保持。
5. 取消或系统返回放弃未保存调整；没有改动时点击完成直接退出。保存失败保留调整，提示重试，用户也可取消。

“全部录音”在包含该项的选择器中固定第一项，不参与排序。新文件夹追加末尾，重命名保持位置，删除不改变其余文件夹相对顺序；当前浏览范围、录音归属及录音排序保持不变。

### 重命名

1. 用户从录音操作菜单选择重命名。
2. 应用预填当前标题，用户修改并确认。
3. 应用更新显示标题和索引；底层音频文件名可由内部标识稳定管理，不以标题修改作为前提。

### 多选与批量操作

1. 用户点击顶部“多选录音”或长按录音行进入多选；长按时选中该条录音。
2. 点击录音行或复选框切换选择；“全选”仅选择当前文件夹与搜索条件下可见的录音，再次操作可取消全选。
3. 选择“移动”后指定目标文件夹，或选择“删除”并确认选中数量，整批录音移入最近删除。
4. 成功后退出多选并刷新列表；取消弹层或操作失败时保留选择，失败时显示提示供重试。若删除包含当前播放录音，先停止播放。
5. 改变搜索关键词、关闭搜索或切换文件夹时清空选择；退出按钮或系统返回退出多选。操作期间禁用选择与范围变更，避免重复提交。

此项仅包含普通列表的批量移动和软删除；最近删除中的批量恢复、永久删除随最近删除功能另行实现。

## 删除与恢复

### 移入最近删除

1. 用户选择删除一条录音。
2. 应用说明录音将移入最近删除，并在确认后标记为已删除。
3. 该录音不再出现在普通录音列表和搜索结果中，但在保留期内可恢复。

### 恢复或永久删除

1. 用户进入最近删除，查看已删除录音及剩余保留时间。
2. 选择恢复时，录音恢复到删除前的文件夹；原文件夹不存在时恢复至全部录音。
3. 选择永久删除时，应用二次确认后移除音频文件与索引，此操作不可撤销。
4. 到达 30 天保留期的录音由本地清理任务删除；清理失败时应在下次合适时机重试。

## 分享

1. 用户选择已完成录音的分享操作。
2. 应用以只读方式向系统分享面板提供录音的实际文件；分享附件名使用录音列表中的标题，AAC 使用 `.aac` 与 `audio/aac`，M4A 使用 `.m4a` 与 `audio/mp4`，MP3 使用 `.mp3` 与 `audio/mpeg`。分享格式依据该录音，而不是当前默认设置，不执行格式转换。
3. 用户选择目标应用或取消分享。
4. 无论结果如何，丫丫录音中的文件、标题、文件夹和播放状态均不改变。

## 手动备份与恢复（BKP-01～07，已确认、待实现）

### 导出备份

1. 用户进入“更多 → 设置 → 备份与恢复”，选择“导出备份”。
2. 查看正常录音数量、大小及包含范围；页面说明不含最近删除、草稿和设置，ZIP 未加密。
3. 通过系统文件选择器选择文件名和保存位置；取消不开始任务。返回后重新检查活动录音和其他写入。
4. 任务开始后显示准备、打包和保存进度；禁止新录音及数据修改，允许浏览和播放。用户可以离开页面，从设置或通知重新进入。
5. 完整写入成功后显示文件名和位置，可主动分享；提示将备份保存到手机之外。取消/失败清理半成品，无法清理时告知残留位置。

### 导入备份

1. 用户选择应用生成的 ZIP，任务进入整包检查并保护数据；格式不支持、损坏或缺失时整体拒绝。
2. 预览显示备份时间、新增、重复、差异冲突数量及文件夹改名结果；明确同 ID 跳过，无覆盖选项。
3. 用户点击“开始导入”，应用准备音频并统一提交索引；同 ID 包括本地最近删除，跳过且不复活；其他本地录音保持。
4. 文件夹同 ID 沿用本地，不同 ID 同名自动添加后缀，新文件夹按备份顺序追加；空文件夹恢复。
5. 完成后显示新增、重复跳过、冲突跳过及改名结果；应用设置不变。全部已存在时明确说明没有新增。

### 取消、等待与中断

返回或离开任务页不取消，等待导入确认时可重新进入，并持续说明数据暂不可修改。用户可主动取消；索引提交短暂阶段不可取消。系统中断后重新打开，先处理任务恢复记录，再执行其他自动写入；未提交任务清理，已提交音频保留，准确说明结果。第一版不续传，未完成任务允许重新开始。

详细范围与边界见 [第一版设计](../architecture/manual-backup-and-restore-design.md)，实现顺序见 [七步计划](../architecture/manual-backup-and-restore-implementation-plan.md)。

## 中断与返回

录音期间发生锁屏、切换应用、音频焦点丢失、存储空间不足或进程恢复等事件时，界面和通知栏反馈应以 [录音生命周期](../architecture/recording-lifecycle.md) 为准。用户返回应用后，必须能判断录音仍在进行、已暂停、已安全保存，还是因异常结束。
