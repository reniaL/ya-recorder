# UI 交互设计

本文定义丫丫录音 MVP 的信息架构、界面职责和交互规则。它约束用户完成高频任务的路径，不预先锁定最终配色、字体、尺寸或具体组件实现。

2026-10-19 的真机与代码评审见 [UI 与交互评审报告](ui-ux-review-2026-10-19.md)。其中包含实现缺口和待决策的设计建议；未确认的建议不替代本文现行规则。

相关的功能边界见 [MVP 功能列表](feature-list.md)，具体的任务步骤见 [用户流程](user-flows.md)，录音期间的系统状态以 [录音生命周期](../architecture/recording-lifecycle.md) 为准。

## 设计目标

REC-08 第三步已接入共享 AAC 后端，默认 AAC，原生能力为 AAC/MP3；第五步选择器仅展示 AAC、MP3，并按能力启用，AAC 附中英文 ADTS/.aac 说明。旧 M4A 内部兼容及活动会话格式保持；第五步设置/显示/分享回归已通过，第四步已接入保存/恢复验证，用户已于 2026-10-14 确认 AAC 设置、录音、播放、分享等功能真机测试正常，REC-08 已完成。下文 REC-07 初始默认 M4A 描述保留既有基线，验收依据见 [真机反馈](../device-feedback.md#aac-功能验收确认2026-10-14)。

REC-08 后续完整交互目标：新录音格式选择器提供 AAC、MP3，默认 AAC；AAC 可附说明“ADTS 文件，后缀 .aac”，保留下次录音生效提示。录音页显示实际会话格式，升级保留的 M4A 会话仍显示 M4A。更新中英文名称与错误引导，不自动回退格式；旧 M4A 继续按原格式播放和分享。保留进度拖动、快进/快退和倍速，ADTS 按播放器支持的近似定位验证，不承诺逐帧精确。详见 [实现计划](../architecture/aac-adts-plan.md)。本文后续 M4A/MP3 描述保留 REC-07 历史基线，以以上 REC-08 当前状态为准。

- 打开应用后，用户立即能查看已有录音并开始新的录音。
- 将录音中的高风险操作与日常浏览操作分开，降低误停止、误取消和误删除的概率。
- 保持主界面紧凑，以列表而非卡片作为录音管理的主要形态。
- 将文件夹、最近删除和设置等低频任务收纳为二级入口，不使用底部导航栏分散注意力。
- 让录音、保存、播放和错误状态始终可见且可理解，不能只用颜色传递状态。

## 信息架构

```text
全部录音或当前文件夹
  |- 搜索
  |- 录音列表
  |    |- 底部播放器
  |    |- 录音详情页：完整播放控制
  |    `- 单条录音操作：重命名、移动、分享、删除
  |- 开始录音
  |    `- 录音页：暂停/继续、停止、取消
  `- 设置（齿轮图标）
       |- 录音、外观与语言偏好
       |- 录音管理：文件夹管理、最近删除
       `- 数据管理：备份与恢复，含导出、导入及任务状态
```

应用只保留这一个主层级。设置返回此前的录音列表与滚动位置。从设置打开文件夹管理、最近删除后，普通返回回到设置；在文件夹管理点击文件夹行则直接回主界面浏览所选文件夹。范围选择器仍提供文件夹管理快捷入口，从此入口普通返回回到列表。

## 导航规则

### 主界面

主界面默认显示“全部录音”，是应用启动、完成录音和大多数返回操作的落点。顶部应用栏包含以下内容：

- 当前浏览范围：显示“全部录音”或当前文件夹名称；点击后在标题下方原地展开范围选择器。
- 搜索入口：进入当前范围内的录音标题搜索。
- 设置入口：右上角齿轮图标，点击直接打开设置，不再弹出更多菜单；长按提示及无障碍名称为“设置”。多选或提交期间禁用。

范围选择器使用锚定在目录标题旁的浮动菜单，视觉样式与应用其他操作菜单一致，菜单采用圆角、浮层阴影和主题表面色，依次提供“全部录音”和已有文件夹，当前范围用主题色勾选标记；底部分隔线后提供“文件夹管理”。文件夹较多时菜单限制最大高度并支持滚动。选择后立即切换列表并关闭菜单；菜单外点击或系统返回可取消。切换范围只影响当前列表，不改变录音数据。“全部录音”始终表示包含所有未删除录音的聚合范围。

当前浏览范围采用可点击的页面标题样式（UX-04）：默认字号 20 逻辑像素、半粗体（`w600`）、主题主要文字色，并跟随系统字体缩放。名称左对齐，与列表内容左侧起点尽量一致；下拉箭头位于名称右侧，名称与箭头整体可点击，触控高度至少 48 逻辑像素。以 20 为实现基准，若真机验证仍偏小，再评估 22。

长名称保持单行并在超长时省略，下拉箭头始终可见；浮动菜单可完整查看名称，无障碍标签保留完整名称并说明“切换录音范围”。保持顶部紧凑布局，不新增常驻目录栏或录音数量副标题。默认字体下目录应具有清晰的标题层级；320 逻辑像素宽、两倍字体与长名称下，标题、箭头与右侧操作不得重叠，浅色和深色下均应可读。实现后通过组件测试验证布局及切换、多选、搜索行为，并用真机确认字号与视觉分量。

主界面不使用欢迎页、仪表盘或独立的“文件夹”底部标签。没有录音时，空状态仍保留开始录音入口；没有文件夹时，范围选择器显示“全部录音”和“文件夹管理”，仍可直接进入创建流程。

### 二级页面

录音详情、文件夹管理、最近删除和设置均为独立页面，顶部提供返回操作和清晰标题。录音详情顶部直接显示录音标题，不显示“录音详情”；标题右侧提供更多操作菜单，支持重命名、移动到文件夹和分享。重命名和移动复用列表页的输入框、目标选择器及存储流程；成功后详情标题或归属立即更新，详情页保持打开并继续使用当前播放对象。分享复用现有系统分享流程。备份保护期间禁用重命名和移动。返回详情来源的列表时恢复此前的文件夹、搜索条件与滚动位置，并停止详情录音的播放。

系统分享面板和系统权限设置属于应用外界面。用户从这些界面返回时，应用应恢复到触发操作前的页面和可用状态。

## 主界面与录音列表

### 列表结构

录音以创建时间倒序的紧凑列表显示，默认字体使用紧凑行高，大字体和换行时自然增高，至少包含：

- 录音标题。
- 创建日期和时间（同年省略年份，跨年保留年份；详情页显示完整日期时间）。
- 时长。
- 播放入口与当前播放状态。
- 更多操作入口。

标题过长时截断显示，但辅助功能标签和重命名输入框应保留完整标题。单条录音的更多操作以菜单或底部弹层提供重命名、移动、分享和删除；删除为破坏性操作，必须与其他操作有明确区分。

录音（列表、详情或保存提示入口）及文件夹重命名成功后，底部 SnackBar 短暂显示“已重命名”，自动消失，无需额外确认；取消或失败不显示成功提示。

普通模式下，左侧以至少 48×48 的播放按钮替代装饰图标，点击在列表内开始播放并显示底部播放器，再次点击暂停或继续，不打开详情。右侧仅保留更多操作。点击标题或录音行其余区域打开该录音的详情页，并立即自动播放；更多操作按钮保持原有菜单行为。列表行本身不承担删除或移动等手势，避免滑动列表时发生高风险操作。多选模式下左侧改为复选框，点击行仅切换选择，不进入详情或触发播放。

标题采用更突出的字重，日期使用次要小字，时长保持易扫读；元信息在窄屏和大字体下允许换行，行高随内容增长。分隔线淡化并与标题起点对齐，保持紧凑列表。当前播放对象使用浅色主题背景和真实状态文字（加载中、播放中、已暂停、未播放或失败）共同标识；切换对象后旧行恢复普通样式。默认标题生成策略及已有标题保持不变。

### 多选模式

顶部提供“多选录音”入口，长按录音行也可进入并选中该条。多选模式下行点击切换勾选，不触发播放；隐藏单条操作菜单，用复选框和选中背景表达状态。范围和搜索入口下方集中显示“退出多选”、已选 N 条及全选/取消全选；已选数量通过辅助功能实时播报，长文字和大字体允许换行。系统返回优先退出多选。

底部只保留移动、删除及提交进度。未选中时禁用批量操作。收起播放器和开始录音按钮，避免与批量工具栏重叠；已有播放可继续，批量删除涉及该录音时停止播放。

全选仅作用于当前可见列表；修改搜索条件、关闭搜索或切换文件夹清空选择，刷新时移除已不可见的选择。移动弹层排除所有选中录音都已归属的目标，允许不同归属的录音统一移动；同属目标的录音保持归属。删除确认显示选中数量，并说明移入最近删除。取消和失败保留选择，成功退出多选并刷新。

顶部选择工具栏持续说明“修改搜索、关闭搜索或切换文件夹会清空已选录音”，在用户改变条件前明确结果；仅打开搜索不清空，实际修改条件后数量立即更新。保留操作期间禁用搜索、范围和退出的规则。

确认/选择目标与执行期间禁用重复操作、范围切换和退出多选；执行时显示进度提示。批量移动和软删除均使用数据库事务，任一选中录音失效时整批回滚；音频文件保持不变。

### 开始录音

主界面有固定、醒目的开始录音入口。Android 首版优先使用符合 Material 3 的悬浮操作按钮，使用麦克风图标与可访问名称表达其用途。

开始录音会进入独立的录音页。若已有活动会话，开始录音入口不可创建第二条会话，而是将用户带回当前录音页。

### 录音期间的返回确认（UIR-01）

录音中及暂停时不允许直接返回录音列表。页面返回按钮、系统返回及返回手势统一询问“要结束这次录音吗？”，提供“保存并结束”“放弃本次录音”“继续录音”；暂停时最后一项显示“保持暂停”。本规则取代此前录音期间浏览列表及会话提示条方案。

弹窗打开不自动暂停或停止录音，说明选择期间录音继续或保持暂停。取消返回、点击弹窗外或弹窗中再次返回仅关闭弹窗，保持会话原状态。保存复用停止与入库流程，文件和索引提交成功后回原列表；失败保留准确错误及既有恢复能力。放弃进入现有不可恢复确认，取消确认仍保留原状态，清理完成后回原列表。

准备、保存及放弃处理期间阻止返回离开和重复操作；不提供不符合生命周期的保存选择。弹窗期间如会话结束、进入保存或更换会话，关闭失效确认，不能执行旧会话操作。异常结果依真实状态展示。

Home、锁屏及切换应用不触发结束确认，仍遵循后台录音策略；返回应用显示同一会话。通知状态继续由录音服务驱动，不假定 Flutter 页面仍在运行。

## 录音页

录音页是单条未完成会话的唯一主控制面，视觉上应比普通列表更专注。页面最少包含：

- 可读的状态文字，例如“正在录音”或“已暂停”。
- 突出的已录时长。
- 本次会话的录音格式（M4A 或 MP3），作为次要状态文字；录音中不提供切换格式操作。
- 暂停与继续控制；同一位置根据状态切换，不同时显示两个互斥按钮。
- 停止并保存控制。
- 取消录音控制。

暂停、继续和停止使用熟悉的图标；图标按钮必须有可访问名称。停止是高频主操作，应有稳定的位置与足够触控面积。取消会放弃未完成录音，必须先弹出确认界面，确认文案应明确指出无法恢复。

录音页采用统一的操作层级（UIR-03 / UIR-04）：

| 用途 | 视觉规则 |
| --- | --- |
| 停止并保存 | 主题色实心主按钮，停止图标；触控高度至少 56 |
| 暂停 / 继续 | 主题色描边次按钮，暂停 / 播放图标；与保存按钮同排、等宽等高，触控高度至少 56 |
| 放弃本次录音 | 居中的危险色文字按钮，触控高度至少 48；不使用横跨整页的描边框 |
| 危险操作最终确认 | 危险色实心按钮及对应前景色，动作名称明确；触控高度至少 48 |
| 取消确认 | 普通文字按钮，默认焦点；仅关闭确认，不恢复或改变录音状态 |

状态图标、状态文字与计时集中显示：录音中使用主题色麦克风与状态文字；暂停使用中性表面色及暂停图标，不保留红色麦克风。准备、保存与放弃处理中使用等待图标与真实状态文字。计时使用主要文字色和等宽数字；窄屏及大字体允许缩放计时以避免溢出。暂停/继续切换预留最长按钮名称所需空间，处理中保留禁用的控制位置，避免误触。格式仍作为次要信息显示。

当前状态指示仅表达生命周期，不表达实际音量；真实音量反馈仍为后续候选，不使用模拟波形。

用户尝试返回时遵循上方 UIR-01 确认流程；只有停止并保存成功或确认放弃并完成清理后才返回录音列表。

录音页的状态及可操作性必须严格映射到录音生命周期：保存期间禁用暂停、继续、停止和取消，直到得到成功或失败结果。保存成功后，应用返回触发录音的列表范围，并使新录音可见；异常结束时，显示已录部分是否成功保存的准确结果。

## 底部播放器

播放器采用固定在主界面底部、位于悬浮录音按钮之上的轻量控制条，用于边浏览列表边听录音，保持简洁布局。它包含：

- 当前录音标题与播放状态。
- 播放或暂停控制。
- 当前进度、总时长和可拖动的进度条。

不在底部播放器增加倍速选择或快进/快退按钮；这些操作放在详情页。当前为非默认倍速时，可显示当前倍速作为状态提示。点击底部播放器的标题打开当前录音的详情页，遵循详情页自动播放及返回即停规则。

播放器与录音按钮共用底部布局区域：播放器在上方，录音按钮在下方右侧，两者间隔 16 逻辑像素，不互相覆盖。底部区域统一避让系统安全区，列表按其实际高度分配可用空间。进度条独占一行，时间与播放控制放在另一行，以适配窄屏和字体放大；没有当前播放录音时只保留录音按钮。

用户开始播放另一条录音时，当前播放立即停止，播放器切换为新录音。播放完成后，播放器保留该录音并回到起始进度，方便再次播放。所有播放操作均不应改变录音所在文件夹或列表排序。

底部播放器与详情页使用相同的进度拖动规则：开始拖动时暂停正在播放的录音，滑块与当前位置文字即时跟随手指，不等待音频跳转；拖动期间播放进度回传不覆盖预览位置。松手后只跳转一次到最终位置，完成前保持预览；拖动前正在播放则恢复播放，原本暂停或已结束则不自动播放。播放中的录音拖到末尾时结束并回到起点；暂停时拖到末尾保持暂停。拖动及跳转提交期间禁用播放、快进/快退和倍速操作；返回、切换录音或播放错误使旧拖动失效，不能延迟恢复播放。

在录音页中不显示底部播放器，且开始新录音前应停止任何现有播放，避免同一应用同时播放和录音。

## 录音详情页

详情页用于专注回放已保存录音，与控制未完成录制的“录音页”分开。顶栏在返回按钮右侧直接显示录音标题，单行超长省略，点击标题可在可滚动弹窗中查看、选择复制完整名称；标题右侧更多菜单提供重命名、移动到文件夹和分享。重命名成功后立即更新标题，移动成功后更新当前录音归属；两项操作均留在详情页，不重置播放对象。分享使用录音当前标题作为附件名并按实际格式提供文件。正文不重复标题，录音日期使用次要文字样式。正文依次显示播放状态、进度条与当前位置/总时长、紧凑播放控制区。

控制区以播放/暂停按钮为视觉中心：播放按钮的水平中心与页面中线一致，快退 5 秒、快进 5 秒等距、对称放在两侧。快进/快退触控区域至少 56 × 56，图标 36；播放/暂停触控区域至少 64 × 64，图标 48。三个按钮保持同排，两侧按钮与播放按钮的边缘间距各为 24，整体宽度 224。播放按钮使用主题色突出，两侧按钮保持相同的轻量视觉样式；在 320、390 宽和默认/两倍字体下保持对称与留白。

倍速使用独立的 `1× ▾` 紧凑按钮，始终在播放组下方水平居中，距播放按钮底部 16，触控高度至少 56；不参与主播放行的宽度计算，避免当前倍速文字长度影响播放按钮居中。取消大尺寸带边框选择框和常驻“播放倍速”标签，保留无障碍说明。点击倍速弹出 `0.75×、1×、1.25×、1.5×、2×` 五档菜单并勾选当前值，当前倍速始终可见。窄屏和字体放大时不缩小触控区域；内容可滚动，主要控制不互相遮挡。加载、失败、进度拖动及倍速提交期间禁用相应操作。

### 进入与返回

- 从列表标题、录音行或底部播放器标题进入后，立即自动播放所选录音。若正在播放另一条，先停止并切换到所选录音，从起点开始播放。
- 若所选录音就是当前播放对象，沿用当前进度与倍速，不重新加载或从头播放；已暂停时自动继续，已播放完成时从起点重新播放。
- 详情页与底部播放器共用同一个播放状态和播放对象，不创建第二个播放器；详情页只显示完整播放器。
- 顶部返回按钮、系统返回及返回手势均停止该录音播放，并收起列表底部播放器，包括从底部播放器进入详情的情况。返回列表不自动恢复此前播放的其他录音。
- “返回即停”仅指退出详情回到列表，不能由切后台、锁屏或页面暂时不可见触发；这些场景的播放策略另行定义。
- 自动播放失败时，显示准确错误与重试入口，保留返回能力，不显示虚假的播放中状态。加载期间返回也必须取消待完成的自动播放，避免回到列表后又开始出声。

### 完整播放控制

快退/快进按音频时间每次跳转 5 秒，不随倍速改变步长；目标位置限定在 0 与总时长之间。暂停时跳转保持暂停；播放时跳转继续播放，到达末尾后结束播放。拖动进度、切换倍速不修改录音文件或元数据。自然播放结束后停留详情页，显示未播放状态并将进度回到起点，不自动返回列表。

## 搜索

搜索由主界面顶部入口进入，打开后将焦点置于搜索输入框。搜索仅匹配当前浏览范围内、未删除的录音标题；不会跨文件夹隐式搜索，也不会搜索最近删除。

搜索输入框替换目录标题时，提示文字明确当前范围：全部录音下显示“搜索全部录音”，具体文件夹下显示“搜索「工作访谈」中的录音”（使用实际文件夹名称），并随当前范围更新。长提示适配可用宽度，不遮挡右侧操作；关闭搜索后恢复当前目录标题。

搜索结果沿用普通录音列表与底部播放器交互。清除关键词或退出搜索时，应恢复原范围、排序和滚动位置。无结果时显示明确的空结果状态，且不提供会修改数据的快捷操作。

## 文件夹管理

文件夹管理页面展示所有逻辑文件夹及各自的录音数量，提供：

- 创建文件夹。
- 重命名文件夹。
- 删除文件夹。

管理页每行显示未删除录音数量，空文件夹显示 0，中英文适配单复数。点击文件夹行返回主界面浏览该文件夹；右侧更多菜单仅负责重命名和删除，不触发浏览。普通返回保留原范围并更新名称；原文件夹被删除时回到全部录音。排序模式下行点击不浏览。读取数量失败显示错误和重试，不将失败当作 0；创建、重命名、删除及导入保护结束后重新读取目录与数量。备份保护期间可浏览，管理写入入口禁用。

录音移动发生在单条录音的更多操作或批量移动中。清除文件夹归属的目标显示为“未分类”（English: Unfiled），与聚合浏览“全部录音”区分；已无归属时不重复展示该目标，批量选择中至少一项有归属时才展示。可用文件夹按保存顺序排列，当前归属不可重复选择。“未分类”是无文件夹归属状态，不新增浏览范围或数据库文件夹，相关录音可在全部录音中找到。

删除非空文件夹时，必须先要求用户选择其中录音的去向：移至未分类或同时移入最近删除。应用不得在未确认结果的情况下删除非空文件夹。

### 文件夹排序（UX-05）

管理页顶部提供“排序”入口，至少有两个文件夹时可用。进入排序模式后，顶部提供“取消”“完成”，显示“拖动右侧手柄调整顺序”提示，每行右侧显示拖动手柄；暂时收起创建、重命名及删除入口。

拖动仅从手柄发起，普通滑动仍浏览列表；拖动过程中其他行随位置变化让位，靠近屏幕边缘时自动滚动。提供带完整文件夹名称的无障碍标签，以及辅助功能上移/下移操作和行菜单中的“上移”“下移”作为替代；首项上移、末项下移禁用。窄屏、大字体及长名称下，手柄和替代操作应容易触达且不遮挡文字。

点击“完成”一次性保存顺序并退出；取消或系统返回放弃本次调整，不额外要求确认。没有改动时直接退出。保存期间显示进度并禁用重复提交、调整与退出；失败保留本次调整，显示“无法保存文件夹顺序，请重试”，允许重试或取消。

文件夹管理、主界面范围选择器、单条与批量移动选择器统一使用保存顺序；浏览中的“全部录音”和移动中的“未分类”（若展示）分别固定首项，不参与排序，目标过滤规则不变。新文件夹追加末尾，重命名保持位置，删除保持其余相对顺序。顺序在应用重启后保持；现有用户升级时沿用升级前的名称排序。排序不改变当前浏览范围、录音归属或录音按创建时间倒序的规则。

## 最近删除

最近删除页面仅展示处于保留期内的录音，并显示删除时间和剩余保留时间。每个条目提供恢复与永久删除操作：

- 恢复将录音放回删除前的文件夹；该文件夹已不存在时恢复为未分类，可在全部录音中找到。
- 永久删除必须二次确认，并明确说明文件将不可恢复。

最近删除不提供开始录音、搜索或底部播放器，避免用户将其误解为普通录音库。

空状态集中显示删除图标、“最近删除为空”和“删除的录音将在这里保留 30 天”，不在顶部重复长说明。“查看恢复规则”打开可滚动对话框，显示完整恢复归属与保留规则；关闭或返回不修改数据。窄屏和大字体允许整页滚动，读取失败显示错误与重试，不将失败当作空库。非空列表仍显示详细恢复说明。

## 设置

首版设置应保持短小，放置用户需要长期记忆的偏好和低频数据工具。已确认的偏好项（REC-07）为：

设置依次分为“录音”（默认格式及说明）、“外观与语言”（主题、语言）、“录音管理”（文件夹管理、最近删除）、“数据管理”（备份与恢复）。分组标题作为辅助功能标题；未提供数据工具时不显示空分组。默认字号和足够宽度下，设置名称在左、当前值在右，右侧使用单个下拉箭头；窄屏、长文案或大字体下允许名称和值上下排列及换行。页面可滚动，导航到管理页面或数据工具使用向右箭头。保存期间禁用新增管理入口，保留进度指示和既有禁用/返回保护。

- 默认录音格式：设置行显示当前值，点击后在该行附近打开带背景遮罩的圆角浮动选项菜单，显示 AAC、MP3 并标记当前选项。点选后即时持久化，成功后更新显示；点菜单外或系统返回关闭菜单。保存失败时保留原值，并在设置行下方提示。辅助说明为“用于下一次录音，已有录音保持原格式”。
- 主题（UX-06）：设置行显示当前选择，点击后在该行附近打开带背景遮罩的圆角浮动选项菜单，显示“跟随系统、浅色模式、深色模式”并标记当前选项，初始默认跟随系统。选择后即时保存并应用于所有页面，重启保持；保存失败保留原主题并提示重试。跟随系统时响应系统主题变化，主题切换不改变录音与播放状态。保存期间禁用重复选择及返回；读取失败提供重试入口。
- 语言（UX-07）：设置行显示当前选择，点击后在该行附近打开带背景遮罩的圆角浮动选项菜单，以各语言自身名称显示“简体中文”“English”，并标记当前选项。初始默认简体中文。保存成功后立即切换整个应用和录音通知，重启保持；点菜单外或系统返回关闭菜单。读取和保存失败分别提供重试，保存期间禁止重复选择与返回。语言与主题、格式偏好独立。已有录音标题、文件夹名不翻译，新保存录音的自动标题使用当前语言。切换不停止录音或播放，不重新创建页面和原生服务。英文使用录音应用常见表达，覆盖按钮、状态、提示与无障碍描述。

三个选择器均在对应设置行附近打开圆角浮动菜单，弹出时用遮罩压暗背景。菜单使用主题表面色与阴影，当前选择以主题色和勾号标记；点击选项、菜单外部或系统返回关闭。同一菜单内各选项等高，按最长文本和当前字体大小计算高度；菜单总高度包含上下留白，完整展示最后一项，超出可用屏幕高度时允许滚动。保存期间禁止重复操作和退出。

设置选项和普通操作/文件夹/倍速菜单共用 `app_theme.dart` 中的样式规则：16 圆角、8 层级阴影、次级表面色、16 水平内边距、正文字号，选中项使用 35% 主色容器背景及勾号。菜单最大宽度 340，距屏幕至少 16；操作菜单按内容取宽，设置选项保留足够宽度以容纳说明。设置选择器保留 32% 黑色遮罩，普通操作菜单沿用 Material 弹出菜单的外部点击关闭方式，不额外压暗背景。危险操作保持主题危险色和明确名称，不与普通选中状态混用。

以下仍是候选项，不随本次格式选择方案一并纳入实现：

- 音频质量：标准或高质量；实现前须确认每档的具体编码参数。
- 默认保存文件夹：新录音默认归属的应用内分类。

不把录音文件路径、采样率、码率等技术细节直接暴露为首版设置项。录音格式变更应即时保存并在下次新建录音时生效，主题即时生效；已完成录音不因设置改变而重新编码或移动。

进行中的会话保持开始时确定的格式，录音页显示该会话格式而非最新偏好。两种格式共用录音、暂停、保存和错误交互；MP3 实时编码不增加“转换中”页面或编码方式设置。编码不可用时提示“无法开始 MP3 录音，请在设置中选择 M4A 后重试”，不静默切换格式。设置控件须支持窄屏、大字体和无障碍读取当前选择。

## 备份与恢复（已确认，待实现）

设置增加“备份与恢复”入口，进入独立页面，不新增主导航。设置属于偏好和低频数据工具入口。页面提供导出、导入及当前任务；单任务运行时另一个操作不可开始。

- 导出摘要：正常录音数量、大小、包含范围及未加密说明；选择系统保存位置，文件名使用日期时间。
- 导入预览：备份时间、新增/重复/冲突数量和文件夹改名；明确合并、同 ID 跳过及原数据保留，不提供覆盖/副本按钮。
- 进度页：阶段名称、阶段字节百分比与数量；无法计算时显示活动状态。返回不取消，设置行和通知可以重新进入，主动取消使用明确按钮。提交索引时禁用取消并说明正在完成。
- 数据保护：相关管理入口禁用并说明正在备份/恢复，覆盖主列表、文件夹、最近删除和录音入口；浏览播放与设置仍可用。等待确认页提示持续保护状态并提供取消。
- 结果页：显示新增、重复跳过、冲突跳过及文件夹改名，或导出文件名/位置；错误持续可见，提供重新开始。分享交接不显示远端上传成功。
  结果采用简短状态标题与普通字号的具体说明，提供“返回录音库”直接返回主界面。中断且无提交证据时明确无法确认是否完整完成，不声称恢复成功；已确认导入提交时说明已导入内容保留，清理失败继续提供重试及残留信息。导出为主按钮，导入为描边次级按钮；ZIP64/4 GiB 导入限制放在导入入口前，选择文件前即可看到。
- 页面及通知提供中英文与复数资源；浅深色、320px 窄屏、两倍字体、屏幕阅读器可操作。切换主题和语言不重启任务，进度播报节流避免反复打断。

任务与页面生命周期解耦，系统中断返回时说明清理或实际提交结果，不无限显示加载。完整规则见 [第一版设计](../architecture/manual-backup-and-restore-design.md)及 [七步计划](../architecture/manual-backup-and-restore-implementation-plan.md)。

## 提示、确认与错误反馈

### 确认操作

以下操作必须显式确认：取消未完成录音、删除录音、永久删除、删除非空文件夹。确认界面须把默认焦点放在取消或返回操作上，破坏性操作应使用清晰的动作名称，不能使用含糊的“确定”。

放弃、单条/批量删除、永久删除、空/非空文件夹删除共用同一确认组件，采用相同排版、取消焦点、危险操作配色和可滚动布局。危险颜色使用主题 `error` / `onError`，适配浅深主题；保存与恢复等普通操作继续使用主题主色。删除菜单和批量删除入口使用相同危险色，可用性不只靠颜色表达。

放弃说明包含实时已录时长及“无法恢复”，确认按钮统一为“放弃本次录音”；软删除明确可在保留期内恢复，永久删除明确文件不可恢复。文件夹删除说明录音去向，保留原有目标选择与确认流程。确认弹窗中的取消、点外关闭和返回都不提交修改。

### 瞬时反馈

重命名、移动、恢复和开始分享等成功操作可采用短暂提示；提示不应成为了解操作结果的唯一方式，列表和页面内容本身也必须立即反映变化。

正常保存录音或确认放弃完成后，顶部显示一条结果提示，约 4 秒后自动消失；提供带“关闭提示”无障碍名称的关闭按钮，可提前关闭。正常保存成功时同时提供可选“重命名”，直接编辑本次保存录音，不要求命名才能完成保存；点击后关闭提示，输入框不受提示计时影响。备份保护或提交处理中不提供此快捷操作；超时后仍可通过录音更多菜单重命名。新成功提示替换旧提示及重命名目标并重新计时，开始下一次录音立即清除旧提示。关闭或超时只影响提示，不改变录音数据；页面销毁时取消计时器。

保存提示、列表与详情的录音重命名框统一在输入框下显示“使用最近录音的标题”（English: Use a recent recording title）。最多 10 个去重后的标题，同文件夹优先、组内按创建时间倒序，排除当前条目、与初始标题同名项及最近删除。点击候选只填入输入框，光标移至末尾并保持编辑焦点，保存才写入；候选异步加载不覆盖正在输入的内容，加载失败或没有候选时保留普通手动重命名。候选显示完整文字并自动换行，内容可滚动，兼容窄屏、大字体与键盘占用空间。

保存成功提示必须在本地索引写入成功后显示。权限拒绝、保存失败等错误提示不自动消失；异常中断后保存的录音持续显示“录音已中断，已录部分已保存”，不作为普通成功提示自动消失。

### 错误与异常

权限拒绝、存储不足、文件不可读和录音中断必须使用能说明后果的状态页面、提示条或对话框。反馈应区分：

- 尚未开始录音，因此没有生成文件。
- 已录部分已成功保存。
- 录音已中断且无法确认文件是否可用。
- 操作失败，但原文件仍保持不变。

对需要用户修复的错误，提供与场景匹配的下一步，例如再次请求权限、前往系统设置或释放存储空间。不得声称“保存成功”，除非文件和索引均按录音生命周期中的保存协议完成。

## 无障碍与适配

- 所有图标按钮提供可访问名称；播放、录音和暂停等状态通过文字、语义和颜色共同表达。
- 主要操作具有足够的触控面积，且录音页的停止与取消操作不会因状态切换而改变位置。
- 支持系统浅色和深色主题，以及系统字体缩放；标题、时长和操作文字溢出时应换行、截断或滚动，而不遮挡控件。
- 弹层、菜单和对话框打开时，键盘与屏幕阅读器焦点进入弹层；关闭后回到触发控件。
- 列表顺序、焦点顺序与视觉顺序一致，方便键盘、辅助开关和屏幕阅读器用户使用。

## 视觉设计边界

首版先遵循 Android Material 3 的可访问性与系统习惯，再形成丫丫录音自己的轻量视觉语言。视觉设计阶段应定义颜色令牌、排版、间距、图标和动效，但必须遵守以下边界：

- 录音状态优先清晰可读，避免装饰性大面积图形占据控制空间。
- 列表以信息密度和连续扫描为优先，不使用层层嵌套的卡片。
- 动效仅用于状态切换、保存完成和播放器进度等有实际反馈价值的场景，不能延迟录音控制。
- 高风险操作与主操作保持明显层级，但不只依赖红色、绿色等颜色区分。
- 全局主题以中性浅灰/深灰作为页面、应用栏、菜单和表面容器颜色，青绿色保留用于选中、播放和主要操作；文字、次要文字和危险色继续使用语义颜色。状态栏与系统导航栏按主题调整图标明暗。浅深主题均检查普通文字、次要文字、选中与错误色的对比度。

## 交互验收

完成 UI 实现前，应验证至少以下结果：

1. 用户启动应用后能在一个主界面内看到录音列表，并以一次操作进入录音页。
2. 录音中及暂停时，页面返回、系统返回和返回手势均先显示结束选择；取消返回保持原状态，保存成功或放弃完成后才回列表，处理中不重复提交。Home、锁屏及切换应用不误触发结束确认。
3. 保存、播放、搜索、移动、删除和恢复后的列表内容与真实数据状态一致。
4. 任意删除或取消操作均有可理解的确认步骤，确认前不改变数据。
5. 系统字体放大、浅色或深色主题、屏幕阅读器和窄屏设备下，主要文字与控制不重叠且仍可操作。
6. 列表播放按钮仅触发底部播放，标题/行点击进入详情并自动播放；多选点击不触发播放或导航。
7. 进入同一条正在播放或暂停的录音详情保留进度与倍速，进入另一条立即切换；任意时刻最多播放一条录音。
8. 所有返回列表的路径均停止详情播放并收起底部播放器，恢复原列表上下文；加载中返回不会导致延迟自动播放。
9. 详情页倍速正确生效；快进/快退每次 5 秒，正确处理开头、末尾、短于 5 秒的录音和暂停状态。
