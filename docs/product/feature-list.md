# 功能列表

本文定义丫丫录音首版（MVP）的产品范围和验收条件。它是开发前的功能基线，不等同于最终发布后的用户手册。

## 产品目标

用户应能在不登录、不联网的前提下，快速录下声音，并在设备本地可靠地查找、整理、回放和分享录音。应用不展示广告、不提供会员功能，也不收集或上传录音内容。

主要使用场景为几分钟的短时间录音。当前开发与发布验收以 1–5 分钟的代表性录音为主，另保留极短录音和操作/异常边界验证；一小时及更长录音的压力测试暂缓，不作为 REC-07 实现、参数选择或当前发布的必过关口。这里的时长是测试取样范围，不是应用录音时长上限。

## MVP 范围

### 录音

| 编号 | 功能 | 验收条件 |
| --- | --- | --- |
| REC-01 | 麦克风权限 | 首次录音前请求麦克风权限；未授权时明确说明无法录音，并允许用户再次请求或前往系统设置。 |
| REC-02 | 开始录音 | 用户可从主界面以单次操作开始录音；开始后显示明确的录音状态和已录时长。 |
| REC-03 | 暂停与继续 | 录音中可暂停，暂停后可继续写入同一条录音；暂停期间时长不增加。 |
| REC-04 | 停止并保存 | 停止操作完成后，录音按本次会话确定的 MP3 或 M4A 格式保存到本地；文件验证与索引提交成功后出现在录音列表中。M4A 使用 AAC-LC 编码，MP3 实时编码，停止后只完成剩余缓冲与文件收尾。 |
| REC-05 | 取消录音 | 用户可放弃尚未保存的录音；应用在明确确认后删除临时文件，且不在列表中留下记录。 |
| REC-06 | 异常保护 | 录音过程中遇到音频焦点丢失、应用切后台、存储异常或系统中断时，应用应依据 [录音生命周期](../architecture/recording-lifecycle.md) 尽力保存已经写入的内容，并向用户反馈结果。 |
| REC-07 | 默认录音格式与实时 MP3 | “更多 → 设置”可选择 MP3 或 M4A，初始默认 M4A；偏好即时保存且重启后保持，下次新建录音生效。MP3 直接由采集的 PCM 实时编码，不先录 M4A 再转换；两种格式均支持暂停/继续、停止、确认取消、播放及分享。当前会话格式固定，旧录音不转换；编码不可用或失败须明确反馈，不静默切换格式。通过自动化与 Android 真机验证，覆盖几分钟录音、极短录音边界、锁屏/后台、连续操作、异常与升级兼容。 |

### 录音浏览与回放

| 编号 | 功能 | 验收条件 |
| --- | --- | --- |
| LIB-01 | 录音列表 | 默认按创建时间倒序展示当前分类下的录音；每项至少显示标题、创建时间和时长。 |
| LIB-02 | 播放与暂停 | 用户可播放和暂停单条已完成录音；再次播放时界面正确反映播放状态。 |
| LIB-03 | 播放进度 | 用户可查看当前播放进度、拖动到指定位置，并显示总时长。 |
| LIB-04 | 倍速回放 | 详情页提供 0.75×、1×、1.25×、1.5×、2× 选项，正确应用并显示当前倍速；同一播放对象进入详情时保持倍速。 |
| LIB-05 | 搜索 | 用户可按录音标题搜索当前可见范围内的录音；空结果应有明确反馈。 |
| LIB-06 | 录音详情与播放入口 | 列表播放按钮使用简洁底部播放器；标题/行及底部播放器标题进入独立详情页并立即自动播放。同一播放对象保留进度，另一条停止原播放并切换；任意返回列表路径停止详情播放、收起底部播放器并恢复列表上下文，加载中返回不产生延迟播放。多选点击仅切换选择。 |
| LIB-07 | 快进与快退 | 详情页提供快进 5 秒与快退 5 秒，按音频时间跳转且不越过开头或末尾；暂停时跳转保持暂停，到达末尾后结束播放，不改变音频文件内容。 |

### 录音管理

| 编号 | 功能 | 验收条件 |
| --- | --- | --- |
| MGT-01 | 自动命名 | 新录音保存时生成基于本地日期和时间的默认标题，且用户可修改。 |
| MGT-02 | 重命名 | 用户可修改录音标题；修改后不改变音频内容、创建时间和所属文件夹。 |
| MGT-03 | 分享 | 用户可通过系统分享面板分享已完成的 MP3 或 M4A 文件；分享附件以录音标题命名，扩展名与 MIME 类型匹配实际格式，且不移动或删除本地原件。 |
| MGT-04 | 删除 | 删除操作需要确认；录音先移入最近删除，而非立即永久删除。 |
| MGT-05 | 最近删除 | 用户可查看、恢复和永久删除已删除录音；未恢复的录音默认保留 30 天后清理。 |
| UX-02 | 多选与批量操作 | 普通录音列表支持进入/退出多选、勾选与全选当前可见录音；可批量移动或经确认移入最近删除。批量操作在数据库事务内完成，失败不产生部分更新；不改变音频文件内容。 |

### 文件夹

| 编号 | 功能 | 验收条件 |
| --- | --- | --- |
| FLD-01 | 创建文件夹 | 用户可创建名称非空且在同一层级唯一的文件夹。 |
| FLD-02 | 浏览文件夹 | 用户可在全部录音与任一文件夹之间切换浏览。 |
| FLD-03 | 移动录音 | 用户可将已完成录音移动到一个文件夹，或移回全部录音。 |
| FLD-04 | 管理文件夹 | 用户可重命名文件夹；删除非空文件夹前，应用必须让用户决定其中录音的去向。 |
| UX-05 | 文件夹手工排序 | 文件夹管理支持排序模式、手柄拖动及上移/下移替代操作；完成时事务保存，取消或系统返回放弃未保存调整，失败不产生部分更新。顺序重启后保持，并统一用于范围及单条/批量移动选择器；“全部录音”固定首项（若展示）。新文件夹追加末尾，重命名保持位置，删除保持其余相对顺序；升级保留既有顺序及数据，不改变录音排序与归属。 |

## 数据与隐私边界

- 录音文件、文件夹和录音索引仅保存在设备本地。
- 文件夹是应用内的逻辑分类，不要求用户管理底层磁盘目录。
- 应用不要求账户登录，不使用广告 SDK，不进行行为追踪。
- 系统分享功能仅在用户主动触发后提供文件给目标应用。
- 首版支持 MP3 与 M4A/AAC-LC 录音，编码完全在设备本地完成；不提供已有录音的格式转换或云端同步。

## 首版不包含

- 云端备份、多设备同步、协作或账户体系。
- 自动转写、内容识别、AI 摘要或在线分析。
- 波形编辑、裁剪、拼接、降噪等复杂音频编辑功能。
- MP3、M4A 之外的录音格式、已有录音的格式转换，以及高级采样率或码率设置。
- 嵌套文件夹、标签、收藏和智能分类。

## 发布前验收

首版至少应在目标 Android 版本与典型设备上验证以下结果：

1. 分别选择 MP3、M4A，连续执行开始、暂停、继续和停止后，可播放保存的录音，时长符合预期；格式偏好重启后保持，升级保留旧 M4A 文件与索引。
2. 录音时锁屏、切换应用或返回前台后，录音状态与文件结果符合录音生命周期规定。
3. 重命名、移动、删除、恢复和分享不会损坏原始音频文件。
4. 断网时，全部 MVP 功能仍可使用；应用不因网络不可用而阻塞。
5. 权限被拒绝、存储不足和系统中断时，用户能了解发生的情况，且已完成部分不会被静默丢弃。
6. MP3 在 1–5 分钟代表性录音中实时编码稳定，停止后无需重编码整段录音；检查音频连续性、时长、缓冲积压、内存和停止收尾耗时，并验证极短录音、编码/写入失败及进程被终止后的恢复结果，不承诺恢复未落盘的内容。一小时录音及长期 CPU/耗电趋势测试暂缓。
